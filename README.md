# Workflow Automation Android
Script otomatisasi alur kerja berbasis Python untuk perangkat Android via Termux.

## Cara Penggunaan
1. Clone repositori:
   git clone https://github.com/SyamsMaulana/workflow-automation-android.git
2. Masuk ke direktori:
   cd workflow-automation-android
3. Salin konfigurasi:
   cp config.json.example config.json
4. Jalankan script:
   python main.py
